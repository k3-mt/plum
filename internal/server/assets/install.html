What plum is

When an AI coding agent — Claude Code, Codex — writes your code, the tests can pass while you have no idea how the code works. plum is a window that stays open next to your editor. It keeps a record of what the agent changed, what that code actually did when it ran, and how much of it you have not read.

What it does

  1. 1Records what the agent did. Every function it changed, kept with the real calls that function made when the code ran — real arguments, real values back.
  2. 2Counts what you have not read. One number for the repository. It only goes down when you have actually looked.
  3. 3Shows a test running, step by step. Pick a test and plum draws the run — which functions ran, in what order, with what values.
  4. 4Reruns when you save. Save a file and the same test runs again. The drawing updates in place.
  5. 5Answers questions from the evidence. Ask why a value changed; the answer comes from recorded runs, not from guessing.

Where it lives while you code

It is meant to stay open while you work. Two ways to keep it:

76 On a second screen, opened out. The full window: the count, the list, and the drawing of the current test.
76 As a narrow panel beside the editor. It narrows to the number alone, large enough to read at a glance; the rest unfolds when you widen it.

Either way it follows along: when the agent finishes more work, the window moves to it on its own.

Let your agent use it

Your agent can use the same evidence. One command, run once on this machine, teaches it how:

plum agent install

Adds a short block to the instructions file your agent already reads. Your own text in it is untouched.

From then on your agent will:

  • offer to set plum up — never without asking
  • ask "want to see what changed, visualised?" when it finishes a piece of work
  • use plum's recorded runs when you ask how the code behaves
  • never run anything slow on its own

Get it working on a repository

The easiest way is to ask your agent. Paste this into Claude Code or Codex, in the repository you want plum on:

Install plum (go install github.com/k3-mt/plum/cmd/plum@latest, or curl -fsSL https://raw.githubusercontent.com/k3-mt/plum/main/install.sh | sh), then run plum init and plum hooks install in this repository, then plum agent install. Then confirm plum records real execution: trace the newest session and check it reports more than 0 events. If it reports 0 events on a Python repo, the test command is running the wrong interpreter — set test_command in .plum/config.toml to the python that has this project's dependencies (your virtualenv's), then re-trace. Finally run plum watch. Tell me what each step printed.

Your agent will ask before it writes anything. plum needs git, and works on Go, Python, JavaScript, TypeScript and dbt.

Or by hand — four commands
1Get the plum command.
go install github.com/k3-mt/plum/cmd/plum@latest
Or: curl -fsSL https://raw.githubusercontent.com/k3-mt/plum/main/install.sh | sh
2Set up the repository.
plum init && plum hooks install
Run inside the repository. Writes .plum/config.toml and a hook that records each agent turn. Touches nothing else.
3Teach your agent.
plum agent install
The same command as above — once per machine, not per repository.
4Leave it watching.
plum watch
Opens this window and keeps it current — it reruns every time you save.
